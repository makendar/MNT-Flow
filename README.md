# MNT Flow

Manufacturing, customer, and cash intelligence workspace, plus a Lead Generation sales and outreach demo kit.

The Next.js app lives in [`web/`](web/README.md). Demo brochures, email sequences, WhatsApp templates, and call scripts are in [`Lead Generation/`](Lead%20Generation/README.md) and inside the app at `/lead-generation`.

## Run locally

```bash
cd web
npm install
cp .env.example .env
npm run setup
npm run dev
```

Open http://localhost:3000. See [`web/README.md`](web/README.md) for demo accounts and architecture.

All companies and people in the demo are synthetic.
